# 経営者論 論述演習

水2「経営者論」小テスト（第1〜5回）の論述対策ページです。`index.html` 1つで全部動きます。

- 論述19問（うち10問は企業名なしで書ける用語・理論中心）：答えを書いて「キーワードチェック」を押すと、入れるべき用語が入っているかを自動で確認
- 解答例（150〜200字）つき
- 回ごとの絞り込み、「企業名なしで書ける問題」、「未クリアだけ」表示
- 書いた答えとクリア状況はそのブラウザに保存されます

## 使い方

`index.html` をダウンロードしてブラウザで開きます。GitHub Pages を有効にすると、URLを開くだけで使えます。

問題は個人の復習用に作ったもので、授業の公式な資料ではありません。
